# Analyse concurrentielle — marché "consultant automatisation IA" (FR)

> Sondage SERP juillet 2026. À approfondir avec DataForSEO si l'extension est installée.

## Enseignements

1. **Personne ne combine** : visage fort + métriques chiffrées + positionnement "architecte" + bilinguisme propre. C'est l'espace de différenciation.
2. Tous les concurrents qui rankent ont **des pages services dédiées** — confirmation que la one-page seule ne suffira pas.
3. Le domaine exact-match (consultantautomatisation.fr) montre que la requête est encore prenable — le niveau d'autorité global reste modéré.
4. Aucun acteur n'occupe la longue traîne **géo Océan Indien / Madagascar / remote francophone**.

## Gaps de contenu identifiés

- Comparatifs outillage honnêtes par un praticien (n8n vs Make vs Zapier niveau architecte)
- Études de cas avec vrais chiffres (les concurrents restent vagues)
- Contenu "dirigeant" sur le ROI (les concurrents parlent aux techs)
- Architecture multi-agents en production (sujet émergent, SERP pauvre)
